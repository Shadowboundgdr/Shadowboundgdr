## 🚀 Come Ottenere Aiuto

### 1. Cerca Prima

Prima di chiedere aiuto, cerca nelle risorse esistenti:

- **README**: Contiene informazioni generali
- **Documentazione**: Guide e manuali
- **GitHub Issues**: Cerca se il problema è già stato segnalato
- **GitHub Discussions**: Cerca se la domanda è già stata fatta

### 2. Scegli il Canale Giusto

Scegli il canale appropriato per il tuo problema:

- **Domande generali**: GitHub Discussions
- **Bug report**: GitHub Issues
- **Proposte di miglioramento**: GitHub Issues
- **Problemi di sicurezza**: Email di sicurezza
- **Emergenze**: Contatto diretto con maintainer

### 3. Fornisci Dettagli

Quando chiedi aiuto, fornisci:

- Descrizione chiara del problema
- Passi per riprodurre (se bug)
- Contesto (versione, sistema operativo, ecc.)
- Screenshot (se applicabile)
- Cosa hai già provato

## ❓ Domande Frequenti

### Domande Generali

**D: Cos'è Shadowbound?**
R: Shadowbound è un regolamento dark fantasy open source basato su D&D 5.2.1 SRD.

**D: È gratuito?**
R: Sì, Shadowbound è completamente gratuito e open source sotto licenza CC-BY-4.0.

**D: Posso usarlo commercialmente?**
R: Sì, puoi usarlo commercialmente, ma devi mantenere l'attribuzione.

**D: Come inizio a giocare?**
R: Leggi la [Guida Rapida](docs/guida-rapida.md) per iniziare.

### Domande Tecniche

**D: Come contribuisco al progetto?**
R: Leggi [CONTRIBUTING.md](CONTRIBUTING.md) per sapere come contribuire.

**D: Come segnalo un bug?**
R: Apri una issue su GitHub usando il template "Bug Report".

**D: Come propongo una nuova funzionalità?**
R: Apri una issue su GitHub usando il template "Feature Request".

**D: Come traduco il progetto?**
R: Leggi la [Guida per Traduzioni](docs/community/guida-traduzioni.md).

### Domande di Gioco

**D: Quanti giocatori servono?**
R: Shadowbound è progettato per 3-6 giocatori.

**D: Quanto dura una sessione?**
R: Una sessione tipica dura 3-4 ore.

**D: Posso giocare online?**
R: Sì, puoi usare piattaforme come Discord, Roll20, o Foundry.

**D: Dove trovo avventure?**
R: Ci sono avventure ufficiali nella sezione "Avventure" e avventure della community nelle GitHub Discussions.

## 🐛 Segnalare Problemi

### Bug Report

Per segnalare un bug:

1. Cerca se il bug è già stato segnalato
2. Se non trovato, apri una nuova issue
3. Usa il template "Bug Report"
4. Fornisci tutti i dettagli richiesti
5. Attendi la risposta dei maintainer

### Feature Request

Per proporre una nuova funzionalità:

1. Cerca se la funzionalità è già stata proposta
2. Se non trovata, apri una nuova issue
3. Usa il template "Feature Request"
4. Descrivi la funzionalità in dettaglio
5. Spiega perché è utile
6. Attendi la risposta dei maintainer

### Problemi di Sicurezza

Per segnalare un problema di sicurezza:

1. NON aprire una issue pubblica
2. Invia una email a security@shadowbound.example.com (coming soon)
3. Descrivi il problema in dettaglio
4. Attieni alla [Security Policy](SECURITY.md)
