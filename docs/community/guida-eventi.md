## 🎯 Tipi di Eventi

### Sessioni di Gioco

- **One-Shot Aperti**: Sessioni aperte a tutti i giocatori
- **Sessioni di Playtest**: Testare nuove avventure
- **Sessioni di Mentorship**: Sessioni con mentori
- **Sessioni Tematiche**: Eventi con temi specifici

### Workshop e Tutorial

- **DM Workshop**: Workshop per migliorare le capacità di DM
- **Player Workshop**: Workshop per migliorare le capacità di gioco
- **Character Creation Workshop**: Workshop per creare personaggi
- **Worldbuilding Workshop**: Workshop per creare ambientazioni

### Competizioni

- **Adventure Jam**: Competizione di creazione di avventure
- **Character Competition**: Competizione di creazione di personaggi
- **DM Competition**: Competizione di narrazione
- **Art Competition**: Competizione artistica

### Social

- **Meetup**: Incontri presenziali
- **Discord Events**: Eventi su Discord
- **AMA (Ask Me Anything)**: Sessioni Q&A con maintainer o contributori
- **Community Hangout**: Sessioni sociali

## 🚀 Come Organizzare un Evento

### 1. Pianificazione

**Definisci l'obiettivo**:
- Cosa vuoi ottenere con l'evento?
- Chi è il pubblico target?
- Qual è il tema dell'evento?

**Scegli il tipo di evento**:
- Sessione di gioco
- Workshop
- Competizione
- Evento sociale

**Definisci i dettagli**:
- Data e ora
- Piattaforma (Discord, Roll20, Foundry, ecc.)
- Numero di partecipanti
- Requisiti (livelli, esperienza, ecc.)

### 2. Pubblicazione

**Crea una discussione**:
- Usa il template per eventi
- Specifica tutti i dettagli
- Aggiungi requisiti e limitazioni
- Include link per registrazione

**Promuovi l'evento**:
- Condividi nelle Discussions
- Annuncia nel Discord (se disponibile)
- Condividi nei social media
- Tagga contributori rilevanti

### 3. Preparazione

**Per sessioni di gioco**:
- Prepara l'avventura
- Crea personaggi pre-generati se necessario
- Prepara mappe o descrizioni visive
- Testa la piattaforma

**Per workshop**:
- Prepara il materiale
- Crea slide o documenti
- Prepara esercizi pratici
- Testa la piattaforma

**Per competizioni**:
- Definisci le regole
- Crea un sistema di giudizio
- Prepara premi
- Testa la piattaforma

### 4. Esecuzione

**Durante l'evento**:
- Arriva in anticipo
- Verifica la connessione
- Benveni i partecipanti
- Segui il piano
- Sii flessibile se necessario

**Dopo l'evento**:
- Ringrazia i partecipanti
- Documenta i risultati
- Chiedi feedback
- Condividi i momenti memorabili

## 📅 Eventi Regolari

### Sessioni Mensili

**Sessione One-Shot Mensile**:
- **Frequenza**: Una volta al mese
- **Tipo**: One-shot aperto a tutti
- **Livello**: Variabile (rotazione)
- **Durata**: 3-4 ore
- **Piattaforma**: Discord + Roll20

**Sessione Playtest Mensile**:
- **Frequenza**: Una volta al mese
- **Tipo**: Playtest di nuove avventure
- **Livello**: Variabile
- **Durata**: 3-4 ore
- **Piattaforma**: Discord + Roll20

### Workshop Trimestrali

**DM Workshop Trimestrale**:
- **Frequenza**: Una volta ogni 3 mesi
- **Argomento**: Tecniche di narrazione
- **Livello**: Intermedio/Avanzato
- **Durata**: 2-3 ore
- **Piattaforma**: Discord

**Character Creation Workshop Trimestrale**:
- **Frequenza**: Una volta ogni 3 mesi
- **Argomento**: Creazione di personaggi
- **Livello**: Principiante
- **Durata**: 2-3 ore
- **Piattaforma**: Discord

## 🎉 Eventi Speciali

### Adventure Jam

**Descrizione**: Competizione di creazione di avventure in 48 ore.

**Dettagli**:
- **Durata**: 48 ore
- **Tema**: Annunciato all'inizio
- **Partecipanti**: Tutti
- **Premi**: Badge speciali, visibilità

**Regole**:
- L'avventura deve essere originale
- Deve seguire il formato di Shadowbound
- Deve essere playtestata
- Deve essere licenziata sotto CC-BY-4.0

### Character Competition

**Descrizione**: Competizione di creazione di personaggi più creativi.

**Dettagli**:
- **Durata**: 1 settimana
- **Tema**: Annunciato all'inizio
- **Partecipanti**: Tutti
- **Premi**: Badge speciali, personaggi evidenziati

**Regole**:
- Il personaggio deve essere bilanciato
- Deve seguire le regole di Shadowbound
- Deve includere backstory dettagliato
- Deve essere originale

### DM Competition

**Descrizione**: Competizione di narrazione tra DM.

**Dettagli**:
- **Durata**: 2 settimane
- **Tema**: Annunciato all'inizio
- **Partecipanti**: DM
- **Premi**: Badge speciali, riconoscimento

**Regole**:
- La sessione deve essere documentata
- Deve essere valutata dai giocatori
- Deve essere originale
- Deve seguire le regole di Shadowbound

### Community Game Jam

**Descrizione**: Creazione collaborativa di un'avventura in 1 settimana.

**Dettagli**:
- **Durata**: 1 settimana
- **Tema**: Annunciato all'inizio
- **Partecipanti**: Tutti
- **Premi**: Badge speciali, avventura pubblicata

**Regole**:
- L'avventura deve essere collaborativa
- Deve seguire il formato di Shadowbound
- Ogni contributore deve essere riconosciuto
- Deve essere licenziata sotto CC-BY-4.0

## 💡 Consigli per Successo

### Per Organizzatori

1. **Pianifica in anticipo**:
   - Annuncia l'evento con almeno 1 settimana di anticipo
   - Prepara tutto il materiale necessario
   - Testa la piattaforma prima dell'evento

2. **Sii chiaro**:
   - Specifica tutti i dettagli nell'annuncio
   - Comunica cambiamenti tempestivamente
   - Rispondi alle domande dei partecipanti

3. **Sii flessibile**:
   - Adattati ai problemi tecnici
   - Modifica il piano se necessario
   - Sii paziente con i partecipanti

### Per Partecipanti

1. **Puntualità**:
   - Arriva in anticipo
   - Verifica la connessione
   - Sii pronto all'inizio

2. **Partecipazione**:
   - Partecipa attivamente
   - Fai domande
   - Condividi le tue idee

3. **Rispetto**:
   - Rispetta gli altri partecipanti
   - Segui le regole dell'evento
   - Sii costruttivo nel feedback

## ❓ Domande Frequenti

### D: Posso organizzare un evento se sono nuovo?

R: Sì! Tutti possono organizzare eventi. Inizia con eventi piccoli e semplici.

### D: Come faccio a promuovere il mio evento?

R: Crea una discussione nelle Discussions, condividi nel Discord (se disponibile), e chiedi ai maintainer di promuoverlo nei social media.

### D: Posso organizzare eventi in altre lingue?

R: Sì! Specifica la lingua nell'annuncio dell'evento.

### D: Cosa faccio se non abbastanza persone si registrano?

R: Puoi cancellare o posticipare l'evento. Comunica tempestivamente ai partecipanti.

### D: Posso ricevere supporto per organizzare un evento?

R: Sì! Contatta i maintainer via GitHub Discussions per ricevere supporto.
