## 🎯 Consigli per Migliorare i Risultati

### Parametri per Midjourney

```
--v 6 --style raw --q 2 --s 750
```

### Parametri per DALL-E 3

```
Use specific colors: dark purple (#2D1B4E) and silver (#C0C0C0). Vector style, clean lines, professional quality.
```

### Parametri per Stable Diffusion

```
Negative prompt: blurry, low quality, text, watermark, complex details, realistic, photograph, 3d render.
Positive prompt: vector style, flat design, clean lines, sharp edges, minimalist, professional, high quality.
```

### Suggerimenti Generali

1. **Sii Specifico**: Usa colori HEX specifici
2. **Evita Testo**: Genera solo il simbolo, aggiungi il testo dopo
3. **Stile Vettoriale**: Specifica sempre "vector style" o "flat design"
4. **Sfondo Bianco**: Richiedi sempre sfondo bianco per facilità di utilizzo
5. **Alta Qualità**: Usa parole come "high quality", "professional", "sharp lines"

## 🔄 Iterazione

### Generazione Multipla

Genera 4-8 varianti per ogni prompt:
- Scegli le migliori caratteristiche di ciascuna
- Combina gli elementi migliori
- Raffina il prompt basato sui risultati

### Feedback Loop

1. Genera loghi con il prompt base
2. Identifica cosa funziona e cosa no
3. Modifica il prompt basato sul feedback
4. Genera nuove varianti
5. Ripeti fino a ottenere il risultato desiderato

---

## 📦 Post-Processing

### Conversione in SVG

Dopo aver generato il logo:
1. Usa strumenti come Vectorizer.ai o Adobe Illustrator
2. Converti l'immagine in SVG vettoriale
3. Pulisci le linee e rimuovi artefatti
4. Crea varianti (monocromatico, invertito)

### Aggiunta del Testo

Aggiungi il testo "SHADOWBOUND" dopo:
- Usa il font Cinzel o simile
- Posiziona sotto o accanto al simbolo
- Mantieni la palette colori
- Assicurati della leggibilità
