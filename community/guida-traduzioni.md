## 🌟 Perché Tradurre

Tradurre Shadowbound in altre lingue offre molti vantaggi:

- **Accessibilità**: Rende il regolamento accessibile a più persone
- **Community**: Espande la community a livello globale
- **Diversità**: Arricchisce il progetto con diverse prospettive
- **Crescita**: Aumenta la visibilità e la popolarità del progetto
- **Collaborazione**: Permette a persone di diverse lingue di contribuire

## 🚀 Come Iniziare

### 1. Scegli una Lingua

Scegli una lingua che:
- Conosci bene (madrelingua o livello avanzato)
- Non è già tradotta
- Hai interesse a mantenere nel tempo

### 2. Fork e Clone

Forka il repository e clonalo localmente:

```bash
git clone https://github.com/TUO_USERNAME/shadowbound.git
cd shadowbound
```

### 3. Crea un Branch

Crea un branch per la traduzione:

```bash
git checkout -b translation/lingua
```

Sostituisci `lingua` con il codice della lingua (es. `en`, `es`, `fr`).

### 4. Apri una Issue

Apri una issue per coordinare la traduzione:

- Titolo: `[Translation] [Lingua] - Traduzione di Shadowbound`
- Descrizione: Indica la lingua e il tuo livello di competenza
- Tag: `translation`, `needs-review`

## 📐 Linee Guida per Traduttori

### Terminologia

Usa la terminologia standard di Shadowbound:

| Italiano | Inglese | Spagnolo | Francese |
|----------|---------|----------|----------|
| Punti Ferita | Hit Points | Puntos de Vida | Points de Vie |
| Punti Magia | Magic Points | Puntos de Magia | Points de Magie |
| Punti Ombra | Shadow Points | Puntos de Sombra | Points d'Ombre |
| Classe Armatura | Armor Class | Clase de Armadura | Classe d'Armure |
| Tiro Salvezza | Saving Throw | Tiro de Salvación | Jet de Sauvegarde |

### Tono e Stile

- **Tono**: Mantieni il tono dark fantasy
- **Stile**: Usa un linguaggio formale ma accessibile
- **Coerenza**: Sii coerente nella terminologia
- **Chiarezza**: Le regole devono essere chiare e comprensibili

### Formattazione

- Mantieni la formattazione Markdown originale
- Non modificare la struttura dei documenti
- Usa tabelle per dati numerici
- Mantieni gli emoji e i simboli

### Note Culturali

- Adatta i riferimenti culturali quando necessario
- Spiega termini specifici di Shadowbound
- Mantieni i nomi propri (luoghi, NPC, deità)
- Aggiungi note culturali se necessario

## 🔄 Processo di Traduzione

### 1. Traduzione

Traduci i file in ordine di priorità:

**Alta Priorità**:
1. `README.md`
2. `docs/guida-rapida.md`
3. `docs/sistema-gioco.md`

**Media Priorità**:
4. `docs/manuale-giocatore.md`
5. `docs/manuale-dm.md`
6. `docs/bestiario.md`

**Bassa Priorità**:
7. `docs/ambientazione.md`
8. `docs/sottoclassi.md`
9. `docs/artefatti.md`

### 2. Revisione

Una volta completata la traduzione:

1. Fai un self-review
2. Chiedi a qualcun altro di revisionare
3. Apri una Pull Request
4. Attendi il feedback dei maintainer

### 3. Aggiornamento

Quando il regolamento originale viene aggiornato:

1. I maintainer ti notificheranno
2. Traduci le modifiche
3. Aggiorna la tua traduzione
4. Apri una PR per le modifiche

## 🏆 Riconoscimenti

### Attribuzione

Ogni traduzione includerà:

```markdown
*Tradotto da: @username*
*Lingua: [Lingua]*
*Revisionato da: @username*
```

### Badge

Traduttori attivi riceveranno badge speciali:

- **Translator**: Per aver tradotto un documento
- **Master Translator**: Per aver tradotto 5+ documenti
- **Legendary Translator**: Per aver tradotto 10+ documenti

### Visibilità

Le traduzioni saranno:

- Evidenziate nel README
- Condivise nei social media
- Presentate nelle newsletter
- Raccomandate ai nuovi giocatori

## ❓ Domande Frequenti

### D: Posso tradurre solo una parte del regolamento?

R: Sì, puoi tradurre solo i documenti che preferisci. Indica quali documenti stai traducendo nella tua issue.

### D: Come faccio a mantenere la traduzione aggiornata?

R: I maintainer ti notificheranno quando ci sono aggiornamenti. Dovrai tradurre le modifiche e aprire una PR.

### D: Posso usare strumenti automatici di traduzione?

R: No. Le traduzioni automatiche non sono accettabili. Devono essere tradotte manualmente da umani.

### D: Come faccio a segnalare errori nella traduzione?

R: Apri una issue con la tag `translation` e specifica l'errore e la correzione suggerita.

### D: Posso tradurre in una lingua non supportata?

R: Sì! Apri una issue per proporre una nuova lingua. I maintainer valuteranno la proposta.
