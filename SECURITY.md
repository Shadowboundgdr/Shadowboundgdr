## Reporting a Vulnerability

Se scopri una vulnerabilità di sicurezza in Shadowbound, ti preghiamo di:

1. **Non aprire una issue pubblica**
2. **Inviare una email a**: security@shadowbound.example.com (coming soon)
3. **Includere nel report**:
   - Descrizione della vulnerabilità
   - Passi per riprodurla
   - Impatto potenziale
   - Suggerimento per la correzione (se possibile)

### Processo di Risposta

- **Risposta iniziale**: Entro 48 ore
- **Analisi**: Entro 7 giorni lavorativi
- **Risoluzione**: Entro 30 giorni (dipende dalla gravità)
- **Pubblicazione**: Dopo la correzione e il rilascio

## Best Practices per la Sicurezza

### Per Contributori

- **Non esporre credenziali**: Mai commitare API keys, password, o token
- **Usa secrets**: Usa GitHub Secrets per dati sensibili
- **Revisiona il codice**: Controlla sempre il codice prima di commitare
- **Segui le linee guida**: Segui le linee guida di sicurezza

### Per Utenti

- **Verifica la fonte**: Scarica solo da fonti ufficiali
- **Usa versioni aggiornate**: Usa sempre l'ultima versione
- **Segnala vulnerabilità**: Segnala qualsiasi vulnerabilità trovata
- **Sii cauto**: Sii cauto con link e allegati

## Policy di Divulgazione

Shadowbound segue le linee guida di divulgazione coordinata:

1. **Ricezione**: Ricezione del report di vulnerabilità
2. **Conferma**: Conferma di ricezione entro 48 ore
3. **Analisi**: Analisi della vulnerabilità
4. **Correzione**: Sviluppo della correzione
5. **Testing**: Testing della correzione
6. **Rilascio**: Rilascio della correzione
7. **Divulgazione**: Divulgazione pubblica

## Coordinate di Sicurezza

Per coordinare la divulgazione di vulnerabilità:

- **Email**: security@shadowbound.example.com (coming soon)
- **GitHub**: Usa la funzione "Security Advisory" di GitHub
