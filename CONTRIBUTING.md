## 🚀 Come Iniziare

### 1. Fork e Clone

Forka il repository e clonalo localmente:

```bash
git clone https://github.com/TUO_USERNAME/shadowbound.git
cd shadowbound
```

### 2. Crea un Branch

Crea un branch per il tuo contributo:

```bash
git checkout -b feature/tuo-contributo
```

### 3. Apri una Issue (Opzionale ma Raccomandato)

Prima di iniziare a lavorare su qualcosa di significativo, apri una issue per discutere:

- Nuove meccaniche di gioco
- Cambiamenti al regolamento esistente
- Nuove ambientazioni o avventure
- Cambiamenti strutturali al progetto

## 📝 Tipi di Contributi

### Contributi al Regolamento

**Nuove Classi:**
- Segui il formato delle classi esistenti
- Includi: descrizione, abilità, tabelle di progressione
- Bilanciamento rispetto alle classi esistenti
- Esempi di build

**Nuove Razze:**
- Descrizione dettagliata
- Tratti e abilità
- Integrazione con l'ambientazione
- Statistiche di gioco

**Nuovi Incantesimi:**
- Nome, scuola, livello
- Descrizione narrativa
- Effetti meccanici precisi
- Componenti (V, S, M)

**Nuovi Mostri:**
- Statistiche complete
- Descrizione e comportamento
- Tattiche di combattimento
- Tesoro e ruolo nell'ambientazione

### Contributi Narrativi

**Avventure:**
- One-shot (3-6 ore di gioco)
- Moduli per campagne più lunghe
- Include: background, NPC, mappe, encounter
- Bilanciamento per diversi livelli

**Ambientazioni:**
- Luoghi dettagliati
- Storia e cultura
- NPC importanti
- Plot hook e segreti

**NPC:**
- Statistiche complete
- Personalità e motivazioni
- Relazioni con altri NPC
- Segreti e plot hook

### Contributi Tecnici

- Correzione bug nel testo
- Miglioramento della documentazione
- Script e tool per la community
- Automazione di processi

### Contributi Artistici

- Illustrazioni di personaggi
- Mappe di luoghi
- Simboli e iconografia
- Layout e grafica

## 🔄 Processo di Contribuzione

### 1. Commit i Tuoi Cambiamenti

Usa messaggi di commit chiari e descrittivi:

```bash
git add .
git commit -m "Aggiunta classe Stregone delle Ombre"
```

### 2. Push e Pull Request

Pusha il tuo branch e apri una Pull Request:

```bash
git push origin feature/tuo-contributo
```

Nella PR, includi:

- **Titolo chiaro**: descrizione breve del contributo
- **Descrizione dettagliata**: cosa hai fatto e perché
- **Issue collegata** (se applicabile)
- **Screenshot** (se contributo visivo)
- **Playtest** (se contributo di gioco)

### 3. Revisione

Il tuo contributo sarà revisionato dalla community. Sii aperto al feedback!

- Rispondi ai commenti
- Apporta modifiche richieste
- Mantieni un tono costruttivo

### 4. Merge

Una volta approvato, il tuo contributo sarà mergiato nel branch principale.

## 📐 Linee Guida

### Stile di Scrittura

- **Tono**: Dark fantasy, maturo ma non gratuito
- **Linguaggio**: Italiano corretto, evita anglicismi non necessari
- **Chiarezza**: Le regole devono essere comprensibili al primo lettura
- **Consistenza**: Usa la terminologia esistente quando possibile

### Formattazione

- Usa Markdown per la documentazione
- Segui la struttura delle sezioni esistenti
- Usa tabelle per dati numerici
- Elenchi puntati per liste di opzioni

### Bilanciamento

- Confronta con contenuti simili esistenti
- Considera impatto sul gioco a diversi livelli
- Evita power creep non necessario
- Documenta le decisioni di bilanciamento

### Attribution

Tutti i contributi devono includere l'attribuzione all'autore originale:

```markdown
*Contribuito da: @username*
*Data: [data]*
```

Per materiale derivato dal SRD:

```markdown
*Basato su: [sezione SRD]*
*Modificato da: @username*
```
